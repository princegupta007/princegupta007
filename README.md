### 🛠 What I build

- **Admin platforms & internal tools** — multi-module back-office products operators run the business in. One Super Admin panel carried **22 modules**: user management, approvals, enquiries, notifications, ads and a bilingual (English/Arabic) CMS.
- **Server-enforced access control** — RBAC models for **4 roles**, enforced strictly on every API endpoint *and* reflected in the UI: separate dashboards per role, permission-based rendering, role-scoped data visibility.
- **Marketplace & order workflows** — bid-to-hire flows, seller onboarding with document approval, 6-step listing wizards, and order / RFQ management across **8 + 6 statuses**, plus subscription tiers with feature gating.
- **Real-time interfaces** — bids, chats and staff rosters pushed over **WebSockets**, with optimistic updates that roll back on server rejection.
- **Performance & frontend architecture** — route-based code-splitting, lazy loading and dependency pruning that cut an initial bundle **~30%**; SSR marketing surfaces on Next.js App Router; shared packages in a **Turborepo monorepo** reused across 3+ applications.
